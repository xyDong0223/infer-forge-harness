# Tools

Only portable `probe/` scripts, replayable `patches/`, and `torch/` references
belong here. Host commands live in `cli/`, their task implementations in
`operations/`, and runtime installers in `runtimes/scripts/`.

Do not add a new top-level task script or a miscellaneous utility directory.
See [source ownership](../docs/architecture/source-layout.zh-CN.md).
