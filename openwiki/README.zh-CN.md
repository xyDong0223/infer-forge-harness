# OpenWiki

> 本文档是 `openwiki/README.md` 的中文译本,内容以英文原版为准。

分层的工程参考资料,按来源划分,各层之间永远不会混淆:

- `vllm-core/`:上游 vLLM 契约和硬件后端集成。
- `vllm-kunlun/`:Kunlun P800 插件实现、算子命名空间,以及带上游行号的已知陷
  阱。
- `harness/`:本项目自身的实践和沉淀的经验(`harness/experiences/`),按碰到
  它们的能力组织,而不是按模型组织。

`SOURCE.md` 登记每一层的来源和证据基线;`index.md` 是阅读路径。

参考资料永远不是证明。任务契约或验证器判定覆盖这里的任何内容,本目录中的任何陈
述都不得用于把结果标记为 PASS。
